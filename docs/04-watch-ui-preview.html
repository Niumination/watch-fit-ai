3 · Jawaban
Dibacakan 2–4 kalimat saja (Voice Formatter), detail penuh tetap bisa dibaca di HP.
Di HP, sesi ini terlihat sebagai panggilan — itu sumber tombol jawab/tutup di jam
Yang tampil di jam
Layar panggilan native (dari self-managed ConnectionService): nama pemanggil "AI Agent", tombol jawab/tutup, indikator mikrofon.
Yang tidak terlihat
Route SCO, streaming WSS ke gateway, VAD/ASR/TTS, adapter agent — semua di HP + VPS, tidak menyentuh jam dan tidak menguras baterai jam lebih dari panggilan biasa.
Kalau app lite gagal dipasang
Rencana B: notifikasi bertombol (Bicara / Ganti agent / Tutup) + Quick Settings tile. Audio tetap dari jam; hanya tombol mulai yang pindah ke HP.

Batasan desain yang dipatuhi mock ini: ES5 (tanpa let/arrow/template literal) · ≤48 KB per halaman · tanpa back-stack (tombol kembali disediakan sendiri) · tanpa audio/mic API · tanpa Wi-Fi · tanpa background. Rujukan: docs/01-riset-dan-arsitektur.md §1.3 dan watch-lite/README.md.
